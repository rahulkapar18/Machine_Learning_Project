\# Dataset



This folder contains the network traffic datasets used by the machine learning experiment.



The original CSV files are not included in the GitHub repository because of their large file sizes.



Required datasets:



\- Tuesday-WorkingHours.pcap\_ISCX.csv

\- Wednesday-workingHours.pcap\_ISCX.csv

\- Thursday-WorkingHours-Morning-WebAttacks.pcap\_ISCX.csv



Place these files inside this `datasets/` folder before running `main.py`.



Dataset: CICIDS2017
